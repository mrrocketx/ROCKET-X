# RocketX Website V3

Complete static RocketX website.

## Includes
Home, About, Focus Areas, Ventures, Investors, Founders, Partners, Insights, Contact, FAQ, Legal/Disclaimer, responsive navigation/footer, premium dark/space design, investment/venture messaging, founder submission interface, contact interface, CSS, JavaScript and favicon.

## Preview
Extract the ZIP and open `index.html` in Chrome, Edge or Firefox.

## Netlify
1. Create/sign into Netlify.
2. Open https://app.netlify.com/drop
3. Extract this ZIP.
4. Drag the entire `ROCKETX_WEBSITE_V3` folder into Netlify Drop.
5. Wait for deployment and use the free `*.netlify.app` address.
6. Rename the Netlify project later if you want a cleaner free subdomain.

Keep `assets` beside all HTML files. Do not upload individual HTML files separately.

## Forms
The forms are interface/demo forms. They display a confirmation message but do not send/store submissions until connected to a form or backend service.
